New:

- File managers offer LinDirStat under Open With for folders once the
  AppImage is integrated into the desktop (for example by AppImageLauncher
  or Gear); LinDirStat opens scanning that folder.

Changed:

- The Open and Save panels (Select Target › Browse, Save/Load Results To
  CSV) are now GNUstep's own, drawn by the Adwaita theme like the rest of
  the app, instead of GTK file choosers. The AppImage no longer bundles
  libs-OpenSave.
