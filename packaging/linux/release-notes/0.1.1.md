**If you have the 0.1.0 AppImage, download this release.** 0.1.0 stops at
startup with "Critical Error in LinDirStat … Unable to find the make_services
tool" on systems without GNUstep installed, before it can check for updates,
so it cannot update itself to 0.1.1.

Fixed:

- The AppImage now includes GNUstep's `make_services` tool, which a first
  launch needs to build its services cache.
