Changed:

- Search runs in the background, so the window stays responsive while
  results are found. Commands that change the tree are disabled until the
  search finishes.
- Opening saved results runs in the background too. The current tree
  stays on screen while the status bar shows that the file is loading.
- Duplicate detection does less work updating results while the
  Duplicate Files tab is hidden. Selecting the tab shows the latest
  groups; visible results still update as hashing progresses.
- Repeated file-type highlights respond faster on large treemaps.
- The treemap waits for a pause in resizing before rebuilding, reducing
  redraws during a drag. It shows a stretched, dimmed preview while
  waiting.

Fixed:

- Select Target, Search and other panels open centred over the main
  window rather than the screen.

Behind the scenes:

- Linux release builds now enable compiler optimizations for LinDirStat
  and its bundled GNUstep backend.

Current limitation:

- Loading saved results shows a status message without a progress
  percentage. Stop is unavailable during the load.
