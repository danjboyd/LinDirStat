Changed:

- The Adwaita theme is updated to 0.1.0-alpha16. A long folder path in the
  header bar is now shortened before the » button instead of running under
  it, and submenus open level with the item that opens them.
- Opening a folder by a relative path from a terminal, such as
  `./LinDirStat-0.1.4-x86_64.AppImage Downloads`, now scans that folder
  relative to where you ran the command, not inside the AppImage.
- Releases are now built on GitHub's runners (the AppImage on Debian 13, the
  DMG on macOS 26) from inputs pinned in the repository, so each one can be
  rebuilt from source. The update feed is still signed on the maintainer's
  machine.
- Every release now has a SHA256SUMS file covering the AppImage and the macOS
  DMG. Check a download with `sha256sum -c --ignore-missing SHA256SUMS`.
