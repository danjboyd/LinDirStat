New, following WinDirStat 2.5.7 to 2.6:

- The Percentage column now shows each item's share of the whole scan, as
  WinDirStat does. Treemap › Show Absolute Percentages switches back to the
  share of the parent folder.
- Add to Exclusion Filter, in the Edit menu and the right-click menus of the
  folder tree, the treemap and the extension list: excludes the selected
  files, folders or extension from future scans and removes them from the
  current one.
- With several items selected, the status bar shows how many there are and
  the files and folders they hold.
- Zoom In is no longer offered for empty folders.
- A folder's scan time no longer counts the time the scan was paused.

Changed:

- The Adwaita theme is updated to 0.1.0-alpha17. Text fields, combo boxes
  and pop-up buttons are as tall as buttons, as in GTK; the » button is
  visible in the dark style; a column's sort arrow no longer covers its
  title; a long folder path in the header bar is shortened before the »;
  submenus open level with the item that opens them; and About LinDirStat is
  a GNOME-style about window.
- The in-app updater reports a failed install at the next launch, and its
  Skip This Version and View Changes buttons work.
- LinDirStat has its own icon in the About window and on its windows, in
  place of the GNUstep logo.
- The column the folder tree is sorted by is wide enough for its title and
  sort arrow ("Percentage" was cut short).
- Opening a folder by a relative path from a terminal, such as
  `./LinDirStat-0.1.4-x86_64.AppImage Downloads`, now scans that folder
  relative to where you ran the command, not inside the AppImage.
- Releases are now built on GitHub's runners (the AppImage on Debian 13, the
  DMG on macOS 26) from inputs pinned in the repository, so each one can be
  rebuilt from source. The update feed is still signed on the maintainer's
  machine.
- Every release now has a SHA256SUMS file covering the AppImage and the macOS
  DMG. Check a download with `sha256sum -c --ignore-missing SHA256SUMS`.
