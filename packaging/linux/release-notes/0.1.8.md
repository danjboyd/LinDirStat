New on Linux:

- Under the Adwaita theme, windows have GNOME's rounded corners and
  shadow.
- The first time you start the AppImage, LinDirStat offers to add itself
  to your applications. It then shows its own icon in GNOME (the overview,
  the dash and Alt+Tab) rather than a generic one. It can then be started
  from the app grid, and offered by "Open With" on a folder. "Not Now" asks
  again a week later. Preferences › Prompts can remove the entry, or add it
  later.

Fixed:

- Under GNOME, the main window opened behind your other windows after
  Select Target's OK, or when LinDirStat was started with a folder, so it
  looked as if the app had quit. It now comes up in front.

Behind the scenes:

- Built with gnustep-packager v0.1.7.
- The release checks no longer leave GNUstep's notification daemon (gdnc)
  running after they finish.
- A thread-safety fix in how exact byte counts are formatted.
