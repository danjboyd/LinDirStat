New, following WinDirStat 2.6 to 2.9:

- A right click on any list's header chooses its columns. Each list
  remembers its own, and the folder tree's Percentage column can now be
  hidden too (also in Preferences › Folder List).
- The folder tree's graph column is now Size Proportion: a bar for the share
  of the parent folder with the share of the whole scan inside it, and a
  tooltip giving both.
- Clean Up › Remove Empty Folders, and Tools › Change Folder Dates to Last
  Change.
- Clean Up › Deduplicate with Hardlink, from the Duplicate Files list: the
  selected copies become hard links to one file. Each file is compared byte
  for byte just before it is replaced.
- Search can find folders as well as files, and filter by owner and by
  logical and physical size. It remembers its last ten searches and shows the
  total size of what it found.
- Filtering can include folders and file names as well as exclude them, can
  leave out files larger or smaller than a size, or newer or older than an
  age, and a folder pattern now covers everything below the folder. Changing
  the filters rescans.
- Each operation that asks for confirmation (move to trash, delete, empty
  trash, deduplicate, remove empty folders, change folder dates) has its own
  switch in Preferences › Prompts.
- In the extension list, double-click a type (or choose Extension - Search)
  to list its files. Options › Group Unregistered Types folds the types with
  no registered description into one row with one colour.
- The File Watcher tab has Start, Pause, Auto Scroll and Clear buttons, and a
  path filter that takes a regular expression.
- Results can be saved and loaded as JSON as well as CSV, in WinDirStat's
  format, including the duplicates list. WinDirStat 2.9 CSV files load, and
  CSV files of Windows folders can be saved and loaded again.
- The treemap can draw a frame and a name header around each folder
  (Treemap › Show Folder Frames).
- Preferences › General › Show seconds in timestamps.
- Select Target takes several folders at once (separated by `|`, or added
  with the button beside Browse…) and scans them together.
- Any number of custom cleanups, added and removed in Preferences ›
  Cleanups; the first ten keep their Ctrl+0–9 shortcuts. Existing cleanups
  are kept.

Fixed:

- An empty or unreadable scan folder no longer shows a black treemap.
- Commands stay unavailable until a finished scan's results are on screen,
  so a quick click can no longer act on the previous scan.
- Remove Empty Folders checks each folder on disk before removing it.
- On macOS, the column the folder tree is sorted by keeps room for its sort
  arrow.

License:

- LinDirStat is now GPL-3.0-or-later (it was GPL-2.0-or-later up to 0.1.4).
  It follows WinDirStat, which moved to GPL-3.0-or-later in 2.9.2, and takes
  its translations from WinDirStat's language files. The packages' notices
  also now cover the bundled URW fonts, the Adwaita icons and the AppImage
